# سياسة الأصول

- الوسائط الخارجية **لا تدخل Git**. تعيش في المجلد المشترك (`guestna-video-assets`، على Drive وقريباً مربوط مع كانفا) وتُربط بـ`npm run assets:link -- --from <المسار>` إلى `public/media/`.
- هيكل المجلد: `<video-name>/...` (مثل `edu/ai/sports.jpg`). كل فيديو يصرّح بما يحتاجه في `src/videos/<name>/assets.json` (المسار، الوصف، المصدر/الرخصة).
- أصل جديد: ضعه في مجلد الأصول المشترك، وأضف سطره إلى `assets.json`، ثم `npm run assets:check`.
- المصادر المقبولة: (1) لقطات وصور جستنا نفسها، (2) ستوك مرخّص عبر Magnific، (3) توليد ذكاء اصطناعي موثّق. **لا تحمّل من يوتيوب/جوجل** (حقوق نشر).
- ترتيب التفضيل للأشخاص: حقيقي من جستنا ← ستوك سعودي مرخّص ← ذكاء اصطناعي.
- صور بدل فيديو للتوفير. وفيديو واحد قصير للمشهد الافتتاحي إذا لزم.
