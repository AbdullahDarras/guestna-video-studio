# قائمة فحص قبل التسليم

- [ ] `npm run lint` بدون أخطاء.
- [ ] إطار من كل مشهد في **منتصف الحركة** وفي نهايتها (تداخل، حواف، نص ملتف).
- [ ] الحركة: `motion-brief.json` محدّث ويطابق ما بُني، و`npm run lint` يمر (يفحص الموجز). بطل واحد لكل مشهد، كاميرا واحدة على الأكثر، لا تتابع حروف في العربية.
- [ ] هوامش: جوانب ≥ 90px، المحتوى بين y 250 و1600، لا عنوان يلمس الحواف.
- [ ] لا شرطات/نقاط حذف في النص. الخط Somar Sans. الأرقام غربية.
- [ ] لا أرقام أو ادعاءات من خارج موقع العميل. شعارات الدفع من موقعهم.
- [ ] الأشخاص بمظهر سعودي فقط؛ المصدر موثّق في `assets.json`.
- [ ] الصوت: Guestna كلمة واحدة، لهجة خليجية (اطلب من المستخدم الاستماع).
- [ ] تصيير كامل: المدة المتوقعة، لا clipping، الصوت موجود.
- [ ] الملخص يذكر التكلفة وما لم يمكن التحقق منه.
