# إنتاج فيديو جستنا

اقرأ `CLAUDE.md` أولاً (القواعد الثابتة). هذا السكل هو **خطوات التنفيذ**.

## المسار (بالترتيب، وفيه ثلاث نقاط موافقة من المستخدم قبل أي صرف كبير)
1. **الموجز:** المنصة المستهدفة، المقاس (ريلز 9:16 افتراضياً)، المدة، الجمهور، المصدر الوحيد للمعلومات (موقع العميل). اقرأ الموقع بالمتصفح ولا تخترع محتوى.
2. **السكربت (موافقة 1):** اكتب النص بلهجة خليجية خفيفة، مقسوماً إلى **فقرات** (تصير مشاهد) وكل فقرة إلى **عبارات** (تظهر عناصر على الشاشة بتوقيت الكلمة). ضعها في `src/videos/<name>/script.json` (انظر `edu/script.json` كمثال، فيه أيضاً نص TTS الكامل). اعرضه على المستخدم قبل التوليد.
3. **موجز الحركة (موافقة 2):** `npm run motion -- brief <name>` ثم عبّئ `motion-brief.json` بمفردات القاموس (انظر القسم التالي). اعرض جدولاً مختصراً (مشهد، بطل، داعم، تأكيد، كاميرا، انتقال) واحصل على الموافقة **قبل** أي توليد صور أو فيديو.
4. **الصوت:** تسجيل واحد متصل → `public/media/<name>/voice/take.mp3` → `npm run voice -- --video <name>`. راجع `references/voice-recipe.md`. يُنتج `voice-final.mp3` و`timing.ts`. بعدها `npm run motion:lint -- <name>` يتأكد أن مدة كل مشهد تكفي حركته.
5. **الأصول:** حدّد لكل مشهد صورة/لقطة. استخدم الأصول المشتركة أولاً (`npm run assets:check`)، ثم ولّد أو جلب ما ينقص (Magnific: images_generate, video_generate, stock). **برومبتات الذكاء الاصطناعي تُبنى من القاموس** بـ`npm run motion -- prompt`. سجّل المصدر في `assets.json`. صور بدل فيديو في القوائم.
6. **المشاهد:** مجلد `src/videos/<name>` (انسخ `npm run new:video`). استخدم `kit.tsx` و`brand.tsx` و`at(scene, phrase)` من `timing.ts`. نفّذ ما في الموجز كما هو؛ إن غيّرت الحركة غيّر الموجز أيضاً. راجع `references/motion-kit.md`.
7. **التحقق:** `npm run lint` (يفحص الكود والموجز معاً)، ثم إطارات `remotion still` من كل مشهد وفي منتصف الحركات. اتبع `references/review-checklist.md`.
8. **التصيير والتسليم (موافقة 3):** `npx remotion render <Id> out/<name>.mp4 --codec=h264`، افحص المدة والصوت، أرسل الملف مع ملخص (ما تغيّر، التكلفة، ما لا تستطيع التحقق منه).

## قاموس الحركة (محرك القرار في الخطوة 3)
المصدر الوحيد `motion/lexicon.json` (183 مصطلحاً: منحنيات، مبادئ، نصوص، أشكال، مؤثرات، انتقالات، كاميرا، لقطات، إضاءة، زمن، عدسة، توليد، مشاكل التوليد). مبني على [قاموس التحريك](https://motioname.com). كل مصطلح له: معنى، **كيف ننفّذه في Remotion/عدّتنا**، وعبارة برومبت إنجليزية.
- المرجع المقروء: `references/motion-vocabulary.md` (يُولَّد بـ`npm run motion:docs`).
- بحث سريع: `npm run motion -- lookup <كلمة عربية أو إنجليزية>`.
- **قاعدة الطبقات:** كل مشهد = **بطل واحد** (الحركة الأساسية) + داعم (حتى 2) + تأكيد (حتى 1) + **حركة كاميرا واحدة على الأكثر**. أكثر من 4 طبقات = فوضى (`fix-chaos`).
- **قواعد التوقيت:** الدخول 6 إلى 30 فريم (200 إلى 1000ms)، الخروج أسرع من الدخول بنحو الربع، الدخول expo-out (هو `EASE` في هويتنا) أو back-out للأيقونات والبطاقات، الحركة داخل الشاشة ease-in-out.
- **العربية:** ممنوع تتابع الحروف وtypewriter وscramble (يقطع اتصال الحروف). استخدم `text-mask-reveal` أو `word-stagger`.
- **الانتقال:** توقيعنا `shape-transition` (الماسة). غيّره فقط إن احتاجته القصة.
- عندما يقول المستخدم مصطلح حركة ("بارالاكس"، "ويب بان"، "ease out"، "تتابع"، "سبرينغ") ابحث عنه بـ`lookup` ونفّذه بمقابله في Remotion بدل تخمين المعنى.
- **لقطات الذكاء الاصطناعي:** `npm run motion -- prompt --subject "..." --camera dolly --light bright-daylight --lens shallow-dof --people`. صورة أولاً ثم image-to-video، حركة كاميرا واحدة، لا نص داخل اللقطة (نصنا من Remotion). عند فشل توليد (تشوه، وميض، كاميرا تتحرك وحدها، أيدٍ) ابحث عن مصطلح `fix-*` وطبّق علاجه.

## تعديلات المستخدم المتكررة (كيف تتعامل)
- "الصوت فيه جملة مصرية/خاطئة" → أعد توليد التسجيل كاملاً بنفس الوصفة (ولّد تسجيلين وابنِ الاثنين)، ولا تقطّع جملاً منفصلة.
- "عنصر متأخر/مبكر عن الصوت" → عدّل `extra` في `at(s, k, extra)` أو أعد قياس التوقيت؛ لا تضع أرقاماً يدوية.
- "مسافات/حواف" → راجع هوامش الأمان في CLAUDE.md وصغّر الخط بدل الضغط.
- "غيّر اللقطات إلى سعودية" → ولّد بالذكاء الاصطناعي (صورة أو فيديو واحد) ووثّق المصدر.
